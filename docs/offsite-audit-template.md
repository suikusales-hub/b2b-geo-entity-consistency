# 站外盘点表模板（复制填写）

> 来自 [seogeo.cc 原文第四节](https://seogeo.cc/b2b-geo-entity-consistency-brand-factory-third-party)：站外是工作量最大的部分，先盘点，再按影响排序修正。

## 盘点范围

用以下关键词分别搜索 **Google、Bing**，并在几个 AI 产品里问「Who is [品牌]」「Is [品牌] a manufacturer or trader」：

- 英文品牌名
- 中文品牌名
- 法定英文名
- 旧名
- 常见拼错

把出现的每个来源记入下表。**中英文都要查**——部分海外 AI 产品也会检索中文页面。

## 来源盘点表

| # | 来源 URL | 出现的名称 | 主体描述（工厂/贸易商） | 认证说法 | 可控性 | 动作 | 状态 |
|---|----------|------------|------------------------|----------|--------|------|------|
| 1 |  |  |  |  | 可控/可申请/不可控 | 统一/下架/301/申请更正/稀释 | 待处理 |

**可控性分类**：

- **自己可控**：平台店铺、社交账号、自有名录 → 直接统一名称、地址、描述模板
- **可申请修改**：行业协会、展会名录、媒体报道 → 发更正请求，附营业执照或证书扫描件
- **不可控**：论坛、旧采购平台 → 无法删除时用新的、一致的第三方提及稀释

## 修正流程（按顺序）

1. **盘点** —— 填完上表
2. **分类** —— 给每行标注可控性
3. **修正可控部分** —— 统一名称/地址/描述；过期证书下架；旧域名 301 到新域名
4. **申请修改** —— 给展会主办方、协会、媒体发更正请求
5. **稀释旧信息** —— 用新的、一致的第三方提及（展会报道、客户案例、行业媒体采访）让正确信息占多数

## 复查

用固定问题集按周复查，不追单次结果。一般以**季度**为单位看实体描述是否稳定纠正——第三方页面的更新需要时间被重新抓取，Bing 的 IndexNow 能通知更新但不保证收录。
